# Contributing to FactureCraft

FactureCraft is in early development. Open an issue to discuss substantial changes before implementing them. For bug reports, include the version or commit, operating system, reproduction steps, and expected and actual behavior.

Use synthetic customers, documents, and payment records in examples and tests. Remove personal data, bank details, credentials, and database files from logs, screenshots, issues, and pull requests.

When the Rust workspace is available, run `cargo fmt --all -- --check` and `cargo test --workspace` before submitting changes. Describe what you tested in the pull request.
