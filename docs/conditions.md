# Vérification des conditions — 18 novembre 2026

Sources officielles consultées :

- https://www.facture.net/terms — section 2 : l'éditeur se réserve le droit de limiter, suspendre ou refuser les fonctionnalités de facturation électronique en cas d'utilisation notamment automatisée. La section 4 interdit de surcharger le système.
- https://www.facture.net/legal — section Copyright : les requêtes automatisées ou semi automatisées des données publiées sans autorisation de Codeur SAS sont visées par une interdiction.
- https://www.facture.net/contact — la FAQ indique qu'il n'existe pas d'API pour créer des factures automatiques.
- https://aide.facture.net/articles/comment-creer-une-facture-depuis-un-autre-outil — l'aide décrit une intégration via Zapier. Cela ne démontre pas l'existence d'une API publique gratuite.

Conclusion de travail : aucune autorisation d'automatiser le compte gratuit ne peut être déduite de ces pages. La portée exacte de ces clauses pour la saisie assistée de données de son propre compte doit être clarifiée avec le service avant activation. Ce constat ne constitue pas une analyse juridique définitive.
